# Mahjong: World Postcards — privacy policy

This repository exists for one reason: Google Play requires every app to
publish a privacy policy at a public URL.

`index.html` is the current policy (from 15 October 2026, version 5: how
soon the game started after an update and through which way the update
came, in the statistics; how long the phone took to prepare a board,
in the statistics; the in-app
update in one Google window and its stages in the statistics; Google
Play Games - the players' leaderboard of stars and a copy of the progress in
Google's cloud - rewarded and full-screen ads by Google AdMob, gameplay
statistics by Google Analytics for Firebase, including the system events
Firebase records on its own, the rule for consent outside the countries
where the consent form is shown, the date check for the daily board, the
in-app rating request and the in-app update check by Google Play).

Earlier versions are kept here under their dates:
- `2026-10-14.html` - 14 October 2026, version 4;
- `2026-10-13.html` - 13 October 2026, version 3;
- `2026-10-09.html` - 9 October 2026, version 2;
- `2026-10-07.html` - 7 October 2026, version 1.

No game code lives here; the game itself is in a private repository.
