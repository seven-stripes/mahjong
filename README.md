# Mahjong: World Postcards — privacy policy

This repository exists for one reason: Google Play requires every app to
publish a privacy policy at a public URL.

`index.html` is the current policy (from 7 October 2026, version 1: Google
Play Games - the players' leaderboard of stars and a copy of the progress in
Google's cloud - rewarded and full-screen ads by Google AdMob, gameplay
statistics by Google Analytics for Firebase, the date check for the daily
board, the in-app rating request and the in-app update check by Google Play).
Earlier versions will be kept here under their dates. No game code lives here;
the game itself is in a private repository.

**Published at:** https://seven-stripes.github.io/mahjong/
